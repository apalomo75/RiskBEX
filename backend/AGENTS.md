# RISKBEX presentation requirement

All current and future user-facing presentation must use professional financial
English exclusively, including Streamlit controls, chart labels, notifications,
errors, API messages presented to users and public product documentation.
English is the only UI language; do not add a multilingual system.
Preserve internal identifiers, API contracts and historical research artifacts.
Use the terminology and product scope recorded in `docs/sprint-4c.md`.
Run the affected lightweight interface checks when changing presentation.
Keep quantitative code, frozen models and historical backtests unchanged during
interface work. Do not download prices, retrain, deploy, schedule or commit
without the relevant task authorisation.
